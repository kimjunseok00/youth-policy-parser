## 원칙

- 공식 원문으로 확인하지 못한 조건은 지어내지 않는다. 근거가 약한 조건은 빼거나 `manual()`(확인 필요)로 둔다.
- 조건식 옆 `#` 주석에 근거를 짧게 적는다.
- 판정이 바뀌면 원문을 확인한 뒤 `tests/regression/persona_expected.json`을 갱신한다.

## 2026-11-02 온통청년 API 수집과 검수 대기 30건

온통청년 청년정책 API(`getPlcy`)로 3,843건을 받아 부산·전국 중 신청 가능한 252건을 초안으로 만들었다.
그중 30건은 API 본문을 읽고 조건식·금액을 채웠다 (`data/curation/batch1~3.json`). **출처는 온통청년 API(2차)**이고,
공식 페이지 확인 전에는 `data/policies/`로 승격하지 않는다. 확인할 항목은 `docs/review_batch1~3.md`에 정책별로 있다.

| 배치 | 정책 | 승격 상태 |
| --- | --- | --- |
| 1 | 부산 10건 (중개보수·이사비, 희망더함주택, 평생함께 주거비, 전세 보증료 지원, 행복주택·통합공공임대, 럭키7하우스, 취업성공풀, 지역인재 장학금, 취업연수생, 온나청년패스) | 확인 대기 |
| 2 | 부산 2건 + 전국 8건 (신용회복, 문화육성, 디딤돌 대출, 버팀목 대출, 보증부 월세대출, 전월세 대출보증, 응시료, 햇살론유스, 미래이음, K-패스) | 확인 대기 |
| 3 | 전국 10건 (청년특화주택, 기숙사형 청년주택, 예술인 적립계좌, 청년미래플러스, K-뉴딜, 부트캠프, 청년인턴, 학자금대출 2종, 특례 채무조정) | 확인 대기 |

수집기가 거르는 것: 마감·기간 지난 정책, zipCd가 전국이어도 기관이 부산 밖 지자체인 정책(경북·충북 등).
같은 상품이 2024년판·2026년판으로 중복 등록된 경우(디딤돌·버팀목·월세대출)는 최신판만 검수했다.
소득 금액 단위는 '만원'이 맞다(디딤돌 7000 = 연 7천만 원 등 3건으로 확인).

확인이 끝난 정책의 승격: `batch*.json`에서 해당 항목의 `review`를 `[]`로 비우고
`uv run python scripts/curate.py data/curation/batchN.json` → `uv run python scripts/promote.py data/drafts/ontong-<번호>.json` (대출·주택 공급처럼 금액이 없는 정책은 `--no-amount` 추가).
